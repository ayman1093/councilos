Security Policy
Supported Versions
Version	Supported
0.0.x (M0, current)	✅ security fixes
Reporting a Vulnerability
If you discover a security vulnerability in councilos-kernel:

Do not open a public issue.
Use GitHub's Private Vulnerability Reporting (Security tab → "Report a vulnerability").
Include: affected file(s), a minimal reproduction, and impact assessment.
You will receive an acknowledgment within 7 days
Scope
The kernel crate (src/, tests/)
CI workflow files
The M0 milestone is a silent skeleton (data contracts + hashing) —no runtime, no network, no secret handling exists yet. The threatsurface will grow with M1+ and this policy will be updated accordingly.

Disclosure
Coordinated disclosure preferred. Please allow up to 90 days beforepublic disclosure of any reported issue.
